# Llama Mobile Capacitor Plugin Example

This is an example application demonstrating the usage of the Llama Mobile Capacitor Plugin.

## Features

- SDK initialization
- Model loading and unloading
- Text generation with and without streaming
- Real-time status indicators
- Model path configuration

## Prerequisites

- Node.js 16 or later
- Capacitor development environment set up:
  - For iOS: Xcode 15 or later
  - For Android: Android Studio 2022 or later
- A valid GGUF model file (e.g., `model.gguf`)

## Getting Started

### Installation

1. Install dependencies:

```bash
npm install
```

### Running the Web App

You can run the web app locally to test the UI:

```bash
npm start
```

Open your browser and navigate to `http://localhost:8080`.

Note: The actual plugin functionality will only work on mobile devices or simulators since it requires native capabilities.

### Adding Mobile Platforms

#### iOS

```bash
npm run cap:add:ios
```

#### Android

```bash
npm run cap:add:android
```

### Syncing Changes

Whenever you make changes to the web app, run:

```bash
npm run cap:sync
```

This will copy the web app files to the native projects.

### Opening the Native Projects

#### iOS

```bash
npm run cap:open:ios
```

Or open `ios/App/App.xcworkspace` in Xcode.

#### Android

```bash
npm run cap:open:android
```

Or open the `android` directory in Android Studio.

## Configuration

### Model Path

Before running the app, update the model path in the app interface:

1. Launch the app on your device or simulator
2. Enter the path to your GGUF model file in the "Model Path" field
3. Tap "Load Model"

Example paths:
- iOS: `/path/to/your/model.gguf` (relative to the app's document directory)
- Android: `/path/to/your/model.gguf` (relative to the app's files directory)

## Usage

1. The app will automatically initialize the SDK when it starts
2. Enter the path to your GGUF model file
3. Tap "Load Model" to load the model
4. Enter a prompt in the text area
5. Tap either:
   - "Generate Text" for non-streaming text generation
   - "Generate Stream" for streaming text generation
6. The response will be displayed below

## Plugin API Demonstrated

- `LlamaMobileCapacitorPlugin.initialize()` - Initialize the SDK
- `LlamaMobileCapacitorPlugin.getVersion()` - Get the SDK version
- `LlamaMobileCapacitorPlugin.loadModel({ path, options })` - Load a GGUF model
- `LlamaMobileCapacitorPlugin.generateText({ prompt, options })` - Generate text without streaming
- `LlamaMobileCapacitorPlugin.generateTextStream({ prompt, options })` - Generate text with streaming
- `LlamaMobileCapacitorPlugin.stopGeneration()` - Stop ongoing generation
- `LlamaMobileCapacitorPlugin.unloadModel()` - Unload the current model

### Events

- `llamamobile:textStream` - Fired when a new token is generated during streaming
- `llamamobile:textStreamComplete` - Fired when streaming generation completes
- `llamamobile:textStreamError` - Fired if streaming generation encounters an error

## Troubleshooting

### Model Not Loading

- Ensure the model path is correct and the file exists
- Check that the model is in GGUF format
- Verify that the app has permission to access the file location

### Text Generation Issues

- Ensure the model has been successfully loaded
- Check the SDK status indicators at the top of the app
- Try reducing the `max_tokens` parameter for faster generation

### iOS Build Issues

```bash
cd ios
pod install
```

### Android Build Issues

```bash
cd android
./gradlew clean
```

### Plugin Not Found

Ensure the plugin is properly installed:

```bash
npm install
npm run cap:sync
```
