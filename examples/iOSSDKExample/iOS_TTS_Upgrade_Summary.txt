## Implementation Details

### Swift Wrapper Implementation
```swift
public func saveAudioToWav(filePath: String, audioData: [Float], sampleRate: Int32 = 24000) -> Bool {
    guard let context = context else {
        return false
    }
    
    return audioData.withUnsafeBufferPointer { buffer in
        filePath.withCString { filePathC in
            llama_mobile_save_audio_to_wav_c(context, filePathC, buffer.baseAddress, Int32(buffer.count), sampleRate)
        }
    }
}
```

### TTS Generation Flow
1. **Text Input**: User enters text to convert to speech
2. **Audio Generation**: System generates audio samples using TTS model
3. **Automatic Saving**: Generated audio is saved to WAV file in temporary directory
4. **Playback**: User can play the saved audio repeatedly

### WAV File Handling
- Files saved in: `/tmp/tts_output_TIMESTAMP.wav`
- Automatically timestamped to prevent overwriting
- Proper WAV format with specified sample rate (24000 Hz)
